# 캐릭터 진행 저장 — 재접속 초기화 방지

- 저장은 현재 브라우저의 캐릭터별 localStorage에 있다. 프로필과 로그인 자체가 서버 진행 동기화를 제공하지는 않는다.
- 로드 effect에서 상태 setter를 호출한 직후 ref만 true로 바꾸면, 같은 렌더의 자동 저장 effect가 초기 Lv.1 / EXP 0을 먼저 기록한다. 실제 운영 빌드에서 기존 Lv.17 저장 앞에 Lv.1 쓰기가 발생하는 것을 재현했다.
- `loadedStorageKey`가 로드한 상태와 함께 다음 렌더에 반영된 뒤에만 저장한다. 현재 선택한 캐릭터의 키와 반드시 일치해야 한다. 로딩 중에는 EXP 지급과 초기화 관련 자동 effect도 대기한다.
- JSON 읽기 실패는 새 게임으로 취급하지 않는다. 기존 저장 문자열을 보존하고 재불러오기 안내를 표시한다. 저장 실패는 재시도 버튼을 표시한다.
- 시나리오 읽은 위치와 특별 보상 변경도 자동 저장 의존성에 포함한다.

검증: 최초 접속의 모든 쓰기에 원래 레벨 유지, 연속 새로고침, 세 캐릭터 전환, Chromium 프로세스 종료/재시작, Lv.3→4 획득 직후 종료/재시작, 손상된 JSON 원본 보존, 저장 용량 오류와 재시도. 이미 과거에 덮어써진 데이터의 복구를 이 수정이 보장하지는 않는다.
