적용 방법

1) npm run dev 켜져 있으면 Ctrl + C로 끄기
2) 이 zip 안의 app 폴더를 C:\Users\ximen\character-chat\app 에 덮어쓰기
3) 캐시 삭제:
   rmdir /s /q .next
4) 실행:
   npm run dev
5) 브라우저에서 Ctrl + Shift + R
